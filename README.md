# APOYO 65 — versión estática

Réplica estática de apoyo65.es lista para GitHub Pages.

## Páginas (mismas URLs que la web original de WordPress)
- `index.html` — portada (`/`)
- `quienes-somos/` — ¿Quiénes somos?
- `equipo-de-investigacion/` — Equipo de investigación
- `publicaciones/` — Publicaciones
- `2024/10/24/que-es-la-soledad/`
- `2024/10/24/la-soledad-en-pandemia/`
- `2024/10/24/consecuencias-de-la-soledad/`
- `2024/10/24/la-soledad-no-afecta-de-igual-forma-a-todas-las-personas-mayores/`
- `404.html` — página de error

## Estructura
- `assets/css/` hojas de estilo del tema
- `assets/img/` imágenes
- `assets/fonts/` tipografías (Inter, Cardo) alojadas localmente
- `assets/js/main.js` menú móvil

## Publicación

GitHub Pages (rama `main`, raíz) con dominio personalizado `apoyo65.es` (archivo `CNAME`).
